GhostHead — 머리 전용 모델

참고 이미지의 검은 눈, 큰 미소, 긴 검은 머리를 바탕으로 제작한 스타일화된 모델입니다.
실사 형태를 그대로 복제한 모델은 아닙니다.

GhostHead.fbx: 단일 메시, UV 1개, 재질 8개. 리깅/애니메이션/표정 모프 없음.
GhostHead.blend: 부위별 편집 가능한 Blender 원본과 미리보기 조명/카메라.
GhostHead_Preview.png: 실제 Blender 모델을 렌더링한 이미지.
validation.json: FBX 재임포트 검사 결과와 측정된 크기.

구성: 얼굴, 눈, 치아, 머리카락, 짧은 목. 몸통 없음.
정점 74,516개 / 삼각형 147,764개.
전체 크기 약 23.1 × 20.3 × 38.1cm (머리카락 포함).
게임용 LOD나 저해상도 리토폴로지는 포함하지 않습니다.

언리얼에는 Static Mesh로 사용할 수 있는 파일입니다.
몸에 붙여 움직이려면 별도의 부착 설정 또는 스키닝 작업이 필요합니다.
기본 색상 재질을 포함하지만 Blender의 절차적 피부 요철과 조명은 FBX에 포함되지 않습니다.
따라서 언리얼에서 미리보기와 같은 외관을 내려면 재질과 조명을 조정해야 합니다.
